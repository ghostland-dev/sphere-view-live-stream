# 360° VR Viewer

Immersive 360° panoramic viewer.

## Features

- React Three Fiber rendering
- Gallery and creation flow

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router
- Three.js
- React Three Fiber

## Getting Started

```bash
git clone https://github.com/ghostland-dev/sphere-view-live-stream.git
cd sphere-view-live-stream
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
